# Leantime 3.10.0 (نسخه اصلاح‌شده Leantime)

این پروژه یک نسخه فارسی‌سازی شده و راست‌چین (RTL) شده از **Leantime** است. (همچنان در حال توسعه)

## پروژه اصلی
این نرم‌افزار بر اساس پروژه [Leantime](https://github.com/Leantime/leantime) ساخته شده است که تحت مجوز **AGPL-3.0** منتشر می‌شود.

## تغییرات ساختاری

- این نسخه برای اجرا در یک زیرمسیر (subdirectory) بهینه شده است.
- به جای اینکه Leantime در ریشه دامنه اجرا شود، می‌توانید آن را در مسیری مانند `www.yourwebsite.com/leantime` اجرا کنید.
- برای این کار، فایل‌های پروژه در پوشه `public` قرار گرفته‌اند تا مستقیماً از طریق وب قابل دسترسی باشند.
- فارسی‌سازی کامل رابط کاربری
- راست‌چین (RTL) کردن تمام بخش‌ها
- [سایر تغییرات خود را اینجا لیست کنید]

## نصب

برای نصب این نسخه از LeanTime، مراحل زیر را دنبال کنید:

### مراحل نصب

**۱. آپلود فایل‌ها**
- تمام محتویات این مخزن را در پوشه `public/leantime` در هاست خود کپی کنید.
- مسیر نهایی باید به صورت `www.yourwebsite.com/leantime` قابل دسترسی باشد.

**۲. تنظیم فایل محیطی (`.env`)**
- فایل `config/.example.env` را به `config/.env` تغییر نام دهید (یا کپی کنید).
- فایل `config/.env` را باز کنید و متغیرهای زیر را تنظیم کنید:

```env
# تنظیمات دیتابیس
DB_HOST=localhost
DB_DATABASE=نام_دیتابیس_شما
DB_USERNAME=نام_کاربری_دیتابیس
DB_PASSWORD=رمز_عبور_دیتابیس

# تنظیمات آدرس سایت
APP_URL=https://www.yourwebsite.com/leantime
```
